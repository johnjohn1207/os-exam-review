# OS Master — 作業系統期中考互動複習系統

## 一、 系統概述與設計架構
本系統為專為大學部「作業系統（Operating Systems）」期中考試量身打造之互動式單頁 Web 應用程式（SPA）。系統針對課程講義（CH1 ~ CH5）與經典權威教材《Operating System Concepts 10th》（恐龍本）之核心章節進行結構化提煉，結合排程演算法模擬引擎、記憶體階層填空挑戰、高頻數值計算實驗室、期中非選問答庫、艾賓浩斯抽認卡與 86 題動態題庫系統，支援高效率反覆演練與弱點補強。

全系統採純靜態前端架構開發（HTML5、CSS3、JavaScript ES6+、KaTeX 數學排版引擎），資料核心模組化分離，完全相容於離線本機執行（支援 `file://` 協定直接雙擊開啟），並具備高度彈性的擴充管理中心，支援日後新單元與題目的即時擴充與備份。

## 二、 核心功能模組

### 1. 章節核心重點導讀（Knowledge Tree）
* **收錄範疇**：完整涵蓋 CH1（作業系統概論與硬體架構）、CH2（行程概念與處理序間通訊 IPC）、CH3（CPU 排程與演算法、即時排程）、CH4（多執行緒程式設計、多核心平行度、隱式執行緒）、CH5（死結特徵、預防避免、銀行家演算法、死結偵測與復原）。
* **恐龍本深入擴充**：
  * **CH1**：補充 64 位元 Native Word（8 Bytes）、Linux 核心紅黑樹（rbtree $O(\log n)$）任務組織、DMA 區塊中斷傳輸機制。
  * **CH2**：補充 IPC 訊息傳遞會合機制（Rendezvous）、佇列容量模型（Zero / Bounded / Unbounded capacity）、郵箱共享競爭處理方式、Chrome 多行程沙盒隔離架構。
  * **CH3**：補充即時 CPU 排程（Real-Time Scheduling: RMS 充分條件利用率檢驗、EDF 絕對截止時間優先排程、比例份額排程）。
  * **CH4**：完整上線多執行緒四大優勢、平行性 vs. 並行性、三大多執行緒模型、隱式執行緒（Thread Pool, Fork-Join, OpenMP, GCD）與多執行緒訊號處理/取消機制。
  * **CH5**：補充資源配置圖宣告邊（Claim Edge）虛線判定安全狀態轉換、死結偵測演算法矩陣分析、死結復原之資源搶佔防飢餓回滾權重機制。
* **即時檢索**：支援關鍵字全文即時過濾（例如輸入「DMA」、「護衛效應」、「fork」、「緩衝區」、「銀行家」、「死結」、「阿姆達爾」、「執行緒池」或「OpenMP」即刻定位）。

### 2. 高頻考點實戰演練（Exam Focal Points）
* **考點一：記憶體階層金字塔（Storage Hierarchy）填空挑戰**
  * 完整覆蓋 7 大層級：Registers、Cache、Main memory、Solid-state disk、Magnetic disk、Optical disk、Magnetic tapes。
  * 提供「完整對照學習」、「期中考隨機挖空 2 格」、「高難度挑戰（隨機挖空 3~4 格）」與「地獄全挖空挑戰」四種演練模式，點擊可即時核對正誤。
* **考點二：三大排程器深度對比（Schedulers Comparison）**
  * 針對長期排程器（Long-term / Job Scheduler）、短期排程器（Short-term / CPU Scheduler）與中期排程器（Medium-term Scheduler）的執行頻率、控制目標（如多道程式設計程度 Degree of Multiprogramming 與調換 Swapping）進行三維度矩陣分析。
* **考點三：行程間通訊（IPC）兩大模型精準對比**
  * 剖析共享記憶體（Shared Memory）與訊息傳遞（Message Passing）在速度、同步責任、會合（Rendezvous）與分散式支援上的差異。
  * 收錄有界限緩衝區（Bounded-Buffer）全空（`in == out`）與全滿（`(in + 1) % BUFFER_SIZE == out`）之判定式與空間利用限制（最多 `BUFFER_SIZE - 1`）。
* **考點四：死結處置四大策略全維度矩陣對照（Deadlock Handling Strategies）**
  * 橫向對比死結預防（Prevention）、死結避免（Avoidance）、死結偵測（Detection）與忽視死結（Ignore / Ostrich）。
  * 深入分析核心機制、先驗資訊需求、資源利用率、運算開銷與代表系統。
* **考點五：死結四大必要條件與破壞預防機制矩陣（Four Conditions & Prevention）**
  * 拆解互斥（Mutual Exclusion）、持有並等待（Hold and Wait）、不可搶佔（No Preemption）與循環等待（Circular Wait）四大條件。
  * 詳析破壞手段（如遞增排序編號 Total Ordering）與伴隨的系統代價（低利用率、飢餓 Starvation）。
* **考點六：教材經典計算手冊與動態死結判斷挑戰器**
  * **動態隨機考題產生器**：支援隨機生成數字矩陣，提供「銀行家演算法安全狀態」與「多重資源死結偵測」雙模式演練。使用者可動筆計算後自主判定是否引發死結，系統即時驗證判定結論，並展開動態 Work 向量與逐步安全序列推導。
  * **教材經典範例完整手冊**：完整收錄教材兩大經典範例大題（銀行家演算法綜合分析題、多重實例死結偵測題），包含 Allocation、Max、Available、Need 矩陣計算、安全演算法逐步 Work 更新歷程與動態資源請求（$Request$）批准判定。
* **考點七：期中高頻數值計算實戰實驗室（Midterm Numerical Calculation Lab）**
  * **題型一：死結臨界最少資源數推導（$M \ge n(m-1)+1$）**：涵蓋均勻需求求最少資源 $M$、逆向求最大行程數 $n$、非對稱需求矩陣，完整展示鴿籠原理與最差卡死狀態推導。
  * **題型二：信號量（Semaphore）計數與行程阻塞判定**：分析初值 $S$ 經一系列 $P$（`wait`）與 $V$（`signal`）操作後之最終計數與等待佇列長度。
  * **題型三：有界限緩衝區空間與指標計算**：推算特定緩衝區大小下的最大存放容量與滿空邊界條件。
  * **題型四：SJF 指數平滑法 CPU 預測推導（$\tau_{n+1} = \alpha t_n + (1-\alpha)\tau_n$）**：隨機產生平滑係數 $\alpha$、初始預估 $\tau_1$ 與連續實際觀測值 $t_i$，要求推導下一次預估長度 $\tau_4$。
  * **題型五：時間量子（Quantum）與上下文切換開銷分析**：推算特定 CPU Burst 在輪轉排程下的切換次數（$\lceil B/q \rceil - 1$）、總消耗時間與 CPU 有效運算佔比。
  * **題型六：阿姆達爾定律（Amdahl's Law）多核心加速比推導**：隨機給定循序比例 $S$ 與處理器核心數 $N$，動態推導加速比 $\text{Speedup} \le \frac{1}{S + \frac{1-S}{N}}$ 與極限值 $\frac{1}{S}$。
  * **題型七：資源配置圖（RAG）環路與死結判定**：隨機產生單一實例與多重實例圖形，要求研判是否存在環路與死結狀態。
  * **題型八：`fork()` 系統呼叫行程樹與子行程數計算**：動態隨機生成連續呼叫、迴圈迭代呼叫及包含 `printf` 輸出情境，要求推算總行程數、新建立子行程數與字串印出次數。
  * **題型九：臨界區間問題（Critical Section）三準則判定**：分析 Peterson 演算法與硬體指令之互斥、進展與有限等待保證。
* **考點八：執行緒 vs. 行程 記憶體資源配置與共享深度矩陣（Thread vs. Process Memory Sharing）**
  * 深度對照同一行程內多執行緒共享之資源（Code、Data、Heap、Open Files、Signals）與各自私有獨立之資源（Thread ID、PC、Registers、Stack）。
  * 剖析行程上下文切換與執行緒上下文切換之開銷本質差異。
* **考點九：三大多執行緒模型全維度深度對照（Multithreading Models Comparison）**
  * 橫向對比多對一（Many-to-One）、一對一（One-to-One）與多對多（Many-to-Many / Two-level）三大模型。
  * 詳析使用者執行緒與核心執行緒映射、阻塞行為、多核心真平行能力與代表作業系統（Linux, Windows, Solaris, GNU）。

### 3. 甘特圖排程計算器與自主手算實戰考場（Gantt Simulator & Practice）
* **演算法完整支援**：
  * 先來先服務（FCFS，非搶占）
  * 最短工作優先（SJF，非搶占）
  * 最短剩餘時間優先（SRTF，搶占式 SJF）
  * 輪轉排程（Round Robin，支援自訂時間量子 $q$）
  * 優先權排程（Priority，支援非搶占與搶占式）
* **動態長條可視化**：精準繪製甘特圖區間、起迄時間刻度與 CPU 閒置狀態（IDLE）。
* **全指標結算表格**：自動推導各行程之到達時間（$A_i$）、CPU Burst（$B_i$）、完成時間（$C_i$）、迴轉時間（$TAT_i = C_i - A_i$）、等待時間（$WT_i = TAT_i - B_i$）與回應時間（$RT_i$），並計算系統平均等待時間、平均迴轉時間與 CPU 利用率。
* **期中排程手算實戰考場**：隨機生成 3~5 個行程排程考題，支援學生在紙上演算後線上填入各行程數值與全系統平均值，系統逐格驗證回饋，並附帶標準答案甘特圖。

### 4. 期中考反覆刷題庫（Quiz Engine）
* **題目量體**：收錄 **86 道** 高強度單選與推導計算題（逐題附帶詳細題解與觀念剖析），完整包含 CH1 ~ CH5 全章節考題。
* **題型專項篩選**：
  * **計算推導題（20 道）**：專攻銀行家演算法、甘特圖指標推導、阿姆達爾定律、EAT 有效記憶體存取、死結臨界資源數等數值題。
  * **觀念判斷題（66 道）**：專攻核心名詞、作業系統模式切換、排程器類型、執行緒模型、IPC 與死結四大條件。
* **分章與全真模擬**：可切換單章專練（CH1、CH2、CH3、CH4、CH5）或全章節混合測驗。
* **自動反饋**：作答後即時標記正誤，若答錯將自動收錄至錯題專攻筆記本。

### 5. 期中非選問答與推導庫（Midterm Essay & Deductive Questions）
* **收錄量體**：精選 **16 道** 恐龍本習題與期中考高頻非選推導大題，總分達 170 分。
* **三大題型維度**：
  * **綜合計算推導大題（9 道）**：
    1. 銀行家演算法全流程安全性判定與 Request 批准（CH5，15 分）
    2. 多演算法甘特圖與排程指標全量計算（CH3，15 分）
    3. 阿姆達爾定律多核心平行極限加速比推導（CH4，10 分）
    4. 巢狀 `fork()` 行程樹建立與狀態輸出推導（CH2，10 分）
    5. 死結預防臨界資源最少需求數推導（CH5，10 分）
    6. 分頁機制結合 TLB 之有效存取時間（EAT）推算（CH1，10 分）
    7. 週期性即時任務速率單調（RMS）與最早截止時間優先（EDF）排程判定（CH3，10 分）
    8. 輪轉排程（RR）時間量子對系統開銷與迴轉時間影響深度推導（CH3，10 分）
    9. 多執行緒多核心平行矩陣乘法工作劃分與加速極限分析（CH4，10 分）
  * **名詞解釋與核心觀念題（4 道）**：
    1. 雙模式（Dual-Mode）操作與軟體中斷（Trap）特權保護機制（CH1，10 分）
    2. 長期、短期、中期三大排程器維度對比（CH2，10 分）
    3. 行程間通訊（IPC）兩大模型深度剖析與有界限緩衝區（CH2，10 分）
    4. 行程（Process）與執行緒（Thread）記憶體配置、開銷與資源共享矩陣（CH4，10 分）
  * **架構設計與申論問答題（3 道）**：
    1. DMA 與中斷驅動 I/O、輪詢（Polling）效能架構深入剖析（CH1，10 分）
    2. 三大多執行緒模型在不同作業系統核心架構下之選型與效能評估（CH4，10 分）
    3. 死結四大必要條件及全域遞增排序打破循環等待之嚴謹反證法證明（CH5，10 分）
* **輔助學習功能**：
  * **破題關鍵思考（Hint）**：引導學生抓出核心公式與解題切入點。
  * **展開/收合標準解答與逐步推導**：提供對齊考試評分標準之完整解答（支援 KaTeX 向量數學排版）。
  * **考試評分標準（Rubric）**：清楚列出各步驟得分權重，掌握搶分細節。
  * **標記掌握狀態**：可將已熟練大題標記為「已掌握」，並即時連動頂端學習指標橫條。

### 6. 錯題專攻筆記本（Mistakes Review）
* 獨立隔離歷次測驗中答錯之考題，支援單獨反覆重測，徹底釐清盲點。
* 當學生確認觀念已釐清時，可點擊「標記為已掌握」自錯題本中移除。

### 7. 主動回想抽認卡（Active Recall Flashcards）
* 擴充至 **29 張** 艾賓浩斯記憶抽認卡，涵蓋四個必要條件、環路與死結關係、宣告邊、鴕鳥策略、阿姆達爾定律、多執行緒四大效益、RMS vs. EDF 等高頻記憶點。
* 支援標記熟練度，追蹤記憶進度。

### 8. 擴充管理中心（Extension & Backup Center）
* **視覺化新增章節**：可透過網頁表單直接輸入新章節名稱、單元標題、重點名詞與說明，即時加載至系統。
* **視覺化新增考題**：支援填寫題目、選項、正解索引與詳細解析。
* **JSON 備份與批次匯入**：支援一鍵複製全系統 JSON 資料，或貼上外部編輯完成之 JSON 資料進行批次熱更新。

## 四、 快速啟動指南

### 方法一：本機直接雙擊開啟（推薦）
本系統採用純前端架構，可直接於檔案總管中雙擊 `index.html`，即可使用預設瀏覽器（Edge、Chrome、Firefox 等）完整執行所有功能，無須安裝 Node.js 或架設本機伺服器。

### 方法二：透過輕量 HTTP 伺服器啟動
若欲透過本機 HTTP 伺服器存取：
```powershell
node server.js
```
伺服器啟動後，於瀏覽器造訪：`http://localhost:3000`。
