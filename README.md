# OS Master — 作業系統期中考互動複習系統

## 一、 系統概述與設計架構
本系統為專為大學部「作業系統（Operating Systems）」期中考試量身打造之互動式單頁 Web 應用程式（SPA）。系統針對課程講義與期中考高頻考點進行結構化提煉，結合排程演算法模擬引擎、記憶體階層填空挑戰、觀念抽認卡與動態題庫系統，支援高效率反覆演練與弱點補強。

全系統採純靜態前端架構開發（HTML5、CSS3、JavaScript ES6+），資料核心模組化分離，完全相容於離線本機執行（支援 `file://` 協定直接雙擊開啟），並具備高度彈性的擴充介面，便於後續課程單元（如 CH4 執行緒、CH5 行程同步、CH6 死鎖等）的即時增補。

## 二、 核心功能模組

### 1. 章節核心重點導讀（Knowledge Tree）
* **收錄範疇**：完整涵蓋 CH1（作業系統概論與硬體架構）、CH2（行程概念與處理序間通訊 IPC）、CH3（CPU 排程與演算法）、CH5（死結特徵、預防避免、銀行家演算法、死結偵測與復原）。
* **考點提示**：每章頂部標註課堂老師提示之核心命題焦點。
* **即時檢索**：支援關鍵字全文即時過濾（例如輸入「DMA」、「護衛效應」、「fork」、「緩衝區」、「銀行家」或「死結」即刻定位）。

### 2. 高頻考點實戰演練（Exam Focal Points）
* **考點一：記憶體階層金字塔（Storage Hierarchy）填空挑戰**
  * 完整覆蓋 7 大層級：Registers、Cache、Main memory、Solid-state disk、Magnetic disk、Optical disk、Magnetic tapes。
  * 提供「完整對照學習」、「期中考隨機挖空 2 格」、「高難度挑戰（隨機挖空 3~4 格）」與「地獄全挖空挑戰」四種演練模式，點擊可即時核對正誤。
* **考點二：三大排程器深度對比（Schedulers Comparison）**
  * 針對長期排程器（Long-term / Job Scheduler）、短期排程器（Short-term / CPU Scheduler）與中期排程器（Medium-term Scheduler）的執行頻率、控制目標（如多道程式設計程度 Degree of Multiprogramming 與調換 Swapping）進行三維度矩陣分析。
* **考點三：行程間通訊（IPC）兩大模型精準對比**
  * 剖析共享記憶體（Shared Memory）與訊息傳遞（Message Passing）在速度、同步責任與分散式支援上的差異。
  * 收錄有界限緩衝區（Bounded-Buffer）全空（`in == out`）與全滿（`(in + 1) % BUFFER_SIZE == out`）之判定式與空間利用限制（最多 `BUFFER_SIZE - 1`）。
* **考點四：死結處置四大策略全維度矩陣對照（Deadlock Handling Strategies）**
  * 橫向對比死結預防（Prevention）、死結避免（Avoidance）、死結偵測（Detection）與忽視死結（Ignore / Ostrich）。
  * 深入分析核心機制、先驗資訊需求、資源利用率、運算開銷與代表系統。
* **考點五：死結四大必要條件與破壞預防機制矩陣（Four Conditions & Prevention）**
  * 拆解互斥（Mutual Exclusion）、持有並等待（Hold and Wait）、不可搶佔（No Preemption）與循環等待（Circular Wait）四大條件。
  * 詳析破壞手段（如遞增排序編號 Total Ordering）與伴隨的系統代價（低利用率、飢餓 Starvation）。
* **考點六：教材經典計算手冊與動態死結判斷挑戰器**
  * **動態隨機考題產生器**：支援隨機生成數字矩陣，提供「銀行家演算法安全狀態」與「多重資源死結偵測」雙模式演練。使用者可動筆計算後自主判定是否引發死結，系統即時驗證判定結論，並展開動態 Work 向量與逐步安全序列推導。
  * **教材經典範例完整手冊**：完整收錄教材兩大經典範例大題（銀行家演算法綜合分析題、多重實例死結偵測題），包含 Allocation、Max、Available、Need 矩陣計算、安全演算法逐步 Work 更新歷程與動態資源請求（$Request$）批准判定。
  * **專業數學符號渲染引擎**：全面整合 KaTeX 向量排版與本機離線正規表示式降級解析器，精確呈現 $R_1, R_2, \dots, R_m$、$\langle P_1, \dots \rangle$、向量比較與複雜矩陣運算式。
* **考點七：期中高頻數值計算實戰實驗室（Midterm Numerical Calculation Lab）**
  * **題型一：死結臨界最少資源數推導（$M \ge n(m-1)+1$）**：涵蓋均勻需求求最少資源 $M$、逆向求最大行程數 $n$、非對稱需求矩陣，完整展示鴿籠原理與最差卡死狀態推導。
  * **題型二：`fork()` 系統呼叫行程樹與子行程數計算**：動態隨機生成連續呼叫、迴圈迭代呼叫及包含 `printf` 輸出情境，要求推算總行程數、新建立子行程數與字串印出次數，打破 $-1$ 的常見考試陷阱。
  * **題型三：SJF 指數平滑法 CPU 預測推導（$\tau_{n+1} = \alpha t_n + (1-\alpha)\tau_n$）**：隨機產生平滑係數 $\alpha$、初始預估 $\tau_1$ 與連續實際觀測值 $t_i$，要求推導下一次預估長度 $\tau_4$。
  * **題型四：時間量子（Quantum）與上下文切換開銷分析**：推算特定 CPU Burst 在輪轉排程下的切換次數（$\lceil B/q \rceil - 1$）、總消耗時間與 CPU 有效運算佔比。

### 3. 甘特圖排程計算器（Gantt Chart & Scheduler Simulator）
* **演算法支援**：
  * 先來先服務（FCFS，非搶占）
  * 最短工作優先（SJF，非搶占）
  * 最短剩餘時間優先（SRTF，搶占式 SJF）
  * 輪轉排程（Round Robin，支援自訂時間量子 $q$）
  * 優先權排程（Priority，支援非搶占與搶占式）
* **動態長條可視化**：精準繪製甘特圖區間、起迄時間刻度與 CPU 閒置狀態（IDLE）。
* **全指標結算表格**：自動推導各行程之到達時間（$A_i$）、CPU Burst（$B_i$）、完成時間（$C_i$）、週轉時間（$TAT_i = C_i - A_i$）、等待時間（$WT_i = TAT_i - B_i$）與回應時間（$RT_i$），並計算系統平均等待時間、平均週轉時間與 CPU 利用率。
* **內建經典考題**：包含護衛效應（Convoy Effect）對比題組、SRTF 搶占題組與 RR 量子題組。

### 4. 期中考反覆刷題庫（Quiz Engine）
* **題目量體**：收錄 52 道高強度單選與推導計算題（逐題附帶詳細題解與觀念剖析），完整包含 CH5 銀行家演算法計算、死結偵測與觀念題。
* **分章與全真模擬**：可切換單章專練（CH1、CH2、CH3、CH5）或全章節混合測驗。
* **自動反饋**：作答後即時標記正誤，若答錯將自動收錄至錯題專攻筆記本。

### 5. 錯題專攻筆記本（Mistakes Review）
* 獨立隔離歷次測驗中答錯之考題，支援單獨反覆重測，徹底釐清盲點。
* 當學生確認觀念已釐清時，可點擊「標記為已掌握」自錯題本中移除。

### 6. 主動回想抽認卡（Active Recall Flashcards）
* 擴充至 23 張艾賓浩斯記憶抽認卡，涵蓋四個必要條件、環路與死結關係、宣告邊、鴕鳥策略等高頻記憶點。
* 支援標記熟練度，追蹤記憶進度。

### 7. 擴充管理中心（Extension & Backup Center）
* **視覺化新增章節**：可透過網頁表單直接輸入新章節名稱、單元標題、重點名詞與說明，即時加載至系統。
* **視覺化新增考題**：支援填寫題目、選項、正解索引與詳細解析。
* **JSON 備份與批次匯入**：支援一鍵複製全系統 JSON 資料，或貼上外部編輯完成之 JSON 資料進行批次熱更新。

## 四、 快速啟動指南

### 方法一：直接雙擊開啟（最簡便）
本專案已完全解除跨來源資源共享（CORS）依賴。在 Windows 檔案總管中，直接雙擊 `index.html` 即可於 Google Chrome、Microsoft Edge 或任何現代瀏覽器中完整執行所有功能。

### 方法二：透過本機 HTTP 伺服器啟動（選擇性）
若習慣透過本機伺服器瀏覽，可於專案目錄下開啟 PowerShell 執行：
```powershell
# 使用 Python 內建伺服器（預設 Port 8000）
python -m http.server 8000
```
開啟瀏覽器訪問：`http://localhost:8000`

## 五、 未來課程彈性增補教學（如耕莘上課更新）

當後續課程進展至 CH4、CH5 時，提供三種彈性擴充方式：

### 方式 A：透過網頁「擴充管理中心」表單新增（推薦）
1. 開啟網站並點擊頂部導覽列「擴充管理中心」。
2. 在左側「新增課程章節與單元」填入章節名稱（如「CH4 執行緒與並行性」）及子單元重點。
3. 點擊「儲存並加入系統」，系統會立即寫入瀏覽器 LocalStorage，並在側邊選單與題庫章節中即時呈現。

### 方式 B：透過「擴充管理中心」批次編輯 JSON
1. 在「擴充管理中心」下方的文字框中，點擊「複製全部 JSON」。
2. 使用文字編輯器（如 VS Code）在 `chapters` 陣列中新增新章節物件，或在 `quizQuestions` 陣列中新增考題。
3. 將修改後的 JSON 貼回文字框，點擊「匯入套用下方 JSON」即完成全系統同步更新。

### 方式 C：直接編輯 `js/data.js`
直接在程式碼中修改 `js/data.js` 的 `OS_DEFAULT_DATA` 物件，此方式為系統的根源預設值，任何使用者重設後皆會以該版本為基準。
